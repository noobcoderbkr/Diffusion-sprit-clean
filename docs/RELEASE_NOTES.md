# RegionCompositor — Windows x64

Stable Diffusion 등으로 편집한 이미지의 특정 영역만 원본에 합성하는 데스크톱 도구입니다.

- 미리보기 중심 인터페이스, 영역 이동·크기 조절, 불투명도·페더·경계 색상 조절
- 한국어 / English 즉시 전환 및 언어 설정 저장
- 별도 PNG 저장과 확인 후 원본 교체
- Python 설치 없이 실행하는 Windows x64 단일 EXE

`RegionCompositor-windows-x64.zip`을 풀고 EXE를 실행하세요. 원본과 편집 이미지를 열어 영역을 조절한 다음 PNG로 저장합니다. 서로 정렬된 이미지의 같은 상대 위치를 합성하며, 자동 배경 제거·스프라이트 시트 생성 기능은 없습니다.

자동 테스트 19개 통과, 패키징된 EXE에서 이미지 열기·합성·PNG 저장 검증 완료. 출력 이미지에는 원본 생성 메타데이터가 보존되지 않습니다.
